Some instructions for getting all the dependencies:
- all dependencies are defined in the requirements.txt file
- open a virtual environment to run all dependencies:
    python3.12 -m venv .venv
    source .venv/bin/activate
- once inside the activated .venv you can run the requirements.txt file
- python -m pip install -r requirements.txt
